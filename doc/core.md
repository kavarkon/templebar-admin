- unauthenticated user перенаправляется на страницу входа
- после успешной аутентификации открывается дашборд

## страница входа
- на странице входа форма для ввода email-адреса и пароля и кнопка для входа

## дашборд
- в центре отображается список мероприятий, имеющихся в базе данных
    - клик по карточке мероприятия открывает страницу редактирования мероприятия

- есть кнопка "меню"
    - если пользователь имеет роль СУПЕР АДМИН, при нажатии на человечка появляется две кнопки: разлогин, управление админами
    - при нажатии на человечка появляется кнопка: разлогин

- есть кнопка "создать новое мероприятие"
    - открывает страницу создания мероприятия, идентичную редактированию
