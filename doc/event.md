# страница создания/редактирования мероприятия

- есть кнопка "вернуться", кнопка "удалить" и поля: 
    1 название
    2 дата и время (день недели генерится автоматически)
    3 описание
    4 постер(где он уже есть) или автоматический постер по-умолчанию(где его еще не устанавливали), какая-то кнопка для замены постера

- на все поля можно нажимать, при изменении содержания любого поля на странице появляется кнопка "сохранить", при нажатии на которую:
    - либо создается новое событие, либо изменяется существующее
    - кнопка сохранения исчезает, возвращая исходное состояние страницы

- кнопка "вернуться" возвращает к списку

- по кнопке "удалить" в центре экрана появляется вопрос, точно ли удалить, и кнопки: "отмена" и "удалить"
    - отмена возвращает на страницу просмотра мероприятия
    - подтвержнение удаляет мероприятие и возвращает к списку
