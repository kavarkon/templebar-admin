# Роутер

## Контракт

- Фронтенд является vanilla JavaScript SPA, собранным Vite.
- Vite собирает один статический `index.html`.
- `src/index.js` выполняет только оркестрацию и вызывает `startRouter`.
- `src/router.js` является публичным контекстом маршрутизации.
- `startRouter` отображает страницу, соответствующую текущему `location.pathname`.
- `navigate(path)` изменяет адрес через `history.pushState` и отображает новую страницу.
- Нажатия Back и Forward повторно отображают страницу через событие `popstate`.
- Неизвестный путь отображает страницу «Страница не найдена».

## Пути

- `/sign-in` отображает страницу входа.
- `/events` отображает список мероприятий.
- `/events/new` отображает форму нового мероприятия.
- `/events/:eventId` отображает форму мероприятия.
- `/admins` отображает список админов.
- `/admins/new` отображает форму нового админа.

## Динамический путь

Для пути `/events/42` роутер извлекает идентификатор `42`. В текущем POC это видно в заголовке «Мероприятие 42».

## POC

- Каждый статический путь отображает свой заголовок.
- Динамический путь мероприятия отображает свой идентификатор.
- Неизвестный путь отображает страницу not found.
