# страница входа 1

## контракт
- unauthenticated user перенаправляется на страницу входа
- на странице входа форма для ввода email-адреса и пароля и кнопка для входа
- после успешной аутентификации открывается страница мероприятий
- если аутентификация не удалась, должно появиться какое-то сообщение

## реализация
- будет один файл sessions.js, который будет подключен на каждую страничку сайта
- все остальные страницы перет вызовом своей логики будут проверять, не нужно ли перенаправление
- будет формочка happy path, тогда мы перенаправляем пользователя на страницу событий
- ошибка "логин или пароль не верны"
