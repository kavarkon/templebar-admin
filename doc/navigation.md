# шапка - меню навигации
- есть кнопка разлогина
- если пользователь СУПЕР АДМИН, есть кнопки: "админы" и "мероприятия"; в противном случае есть только надпись "мероприятия"
- нажатие на разлогин очищает куку и перенаправляет на страницу входа

## мероприятия/админы
- то, на какой странице нахотится СУПЕР АДМИН, выделяет кпопку "мероприятия" или "админы"
- при нажатии на кнопку "мероприятия" происходит перенаправление на страницу мероприятий
- при нажатии на кнопку "админы" происходит перенаправление на страницу админов
