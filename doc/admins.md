# страница управления админами

- на странице админов есть кнопка "меню", кнопка "добавить админа" и список существующих админов

## меню
- при нажатии на кнопку меню появляется кнопка "разлогин" и кнопка "управление мероприятиями"
    - нажатие на разлогин очищает куку и перенаправляет на страницу входа
    - при нажатии на кнопку управления мероприятиями происходит перенаправление на страницу мероприятий

## список админов 
- список карточек, каждая из которых содержит: 
    - имя с фамилией или отчеством(или чем-то еще, создающим уникальное соцетание) для идентификации админов СУПЕР АДМИНОМ
    - статус
    - кнопку действия
- карточки отсортированы по первой букве имени

### кнопка действия
- при нажатии появляется кнопка "заблокировать"/"разблокировать" и кнопка "удалить"
- при нажатии "заблокировать"/"разблокировать" в центре экрана появляется вопрос, точно ли заблочить/разблочить этого админа, и кнопки отмены и подтверждения
    - отмена возвращает в список
    - подтверждение меняет статус админа и возвращает в список, где видно измененный статус
- при нажатии "удалить" в центре экрана появляется вопрос, точно ли удалить этого админа, и кнопки отмены и подтверждения
    - отмена возвращает в список
    - подтверждение удаляет админа и возвращает в список, где больше нет этого админа


## добавить админа
- при нажатии на кнопку открывается страница регистрации нового админа
