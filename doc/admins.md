# страница управления админами
если пользователь не СУПЕР АДМИН, то ему показывается сообщение от отсутствии прав

на странице админов есть кнопка "добавить админа" и список существующих админов


## список админов
- список карточек, каждая из которых содержит:
    - имя с фамилией или отчеством
    <!-- - кнопку редактирования -->
    - кнопку удаления
- карточки отсортированы по первой букве имени

### кнопка удаления
при нажатии "удалить" в центре экрана появляется вопрос, точно ли удалить этого админа, и кнопки отмены и подтверждения
    - отмена возвращает в список
    - подтверждение удаляет админа

## добавить админа
при нажатии на кнопку открывается страница регистрации нового админа

- на странице регистрации нового админа есть поля:
    - имя с фамилией/отчеством/кликухой
    - электронная почта
    - пароль
    - повторить пароль
- есть кнопка "зарегистрироваться"
- есть кнопка возврата на страницу управления админами

- поля проверяют формат вводимых данных, в случае проблем поле будет подсвечиваться
    - почта валидная?
    - Имя с фамилией/отчеством не пустое
    - совпадение двух паролей

- при успешной регистрации перенаправляемся в список админов
- если с сервера пришло сообщение о проблеме, сверху всей формы появится общее сообщение об ошибке, под полями появятся ошибки валидации
