# регистрация админов

- на странице есть поля:
    - имя для идентификации СУПЕР АДМИНОМ
    - электронная почта
    - пароль
    - повторить пароль
- есть кнопка регистрации

- поля проверяют формат вводимых данных и совпадение двух паролей, в случае проблем под полями появляются сообщения

- при успешной регистрации формы пропадают, появляется сообщение с именем админа, что он зареган, и кнопка возврата на страницу админов, где теперь есть новый админ
- если с сервера пришло сообщение о проблеме, под кнопкой регистрации появляется сообщение
