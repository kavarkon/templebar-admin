# страница мероприятий

на странице мероприятий есть кнопка "добавить мероприятие" и список мероприятий из базы данных

## список мероприятий
- список мероприятий представляет из себя список карточек, каждая из которых содержит: статус "черновик?"(может быть в виде другого цвета фона карточки), название, запланированную дату, день недели и время
- карточки отсортированы по запланированной дате по-убыванию
- при нажатии на карточку открывается страница формы мероприятия с загруженными данными

## добавить мероприятие
при нажатии на кнопку открывается страница формы мероприятия с пустыми полями с заглушками

# страница формы мероприятия
- есть кнопка "вернуться", кнопка "удалить", кнопка "сохранить" и поля:
    - чекбокс: черновик?
    - название
    - дата и время (день недели генерится автоматически)
    - описание
    - постер(где он уже есть) или автоматический постер по-умолчанию(где его еще не устанавливали)
    - кнопка "заменить постер". при клике по ней должна открываться загрузка файла, а если файл уже загружен, то рядом с этим полем должна показываться картинка
    - кнопка "удалить постер"
- при нажатии на кнопку "сохранить" либо создается новое событие, либо изменяется существующеe
- кнопка "вернуться" возвращает к списку

- по кнопке "удалить" в центре экрана появляется вопрос, точно ли удалить, и кнопки: "отмена" и "удалить"
    - отмена возвращает исходный вид
    - подтвержнение удаляет мероприятие и возвращает к списку
