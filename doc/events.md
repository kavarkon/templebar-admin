# страница мероприятий

- на странице мероприятий есть кнопка "меню", кнопка "добавить мероприятие" и список мероприятий из базы данных

## меню
- при нажатии на кнопку меню появляется кнопка "разлогин", нажатие на которую очищает куку и перенаправляет на страницу входа
- если юзер имеет роль СУПЕР АДМИН, то при нажатии на меню появляются кнопки "управление админами" и "разлогин"
    - при нажатии на кнопку управления админами происходит перенаправление на страницу админов

## список мероприятий
- список мероприятий представляет из себя список карточек, каждая из которых содержит: название, запланированную дату, день недели и время
- карточки отсортированы: сверху тех мероприятий, которые  должны состояться позже
- при нажатии на карточку открывается страница просмотра конкретного мероприятия

## добавить мероприятие
- при нажатии на кнопку открывается страница, идентичная странице просмотра мероприятия, но с полями пустыми или отображающими заглушки-примеры
